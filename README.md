# Multi-Number and Scientific Calculator in C

A menu-driven calculator developed using C that performs basic arithmetic and scientific operations, including trigonometric functions, logarithms, exponentials, and power calculations. It supports sequential calculations and error handling, demonstrating the practical application of fundamental C programming concepts.

## Project Objective

To develop an efficient and user-friendly calculator using C programming concepts to perform basic and advanced mathematical calculations accurately.

## Features

- Basic arithmetic operations: Addition, Subtraction, Multiplication, and Division
- Scientific functions: Sin, Cos, Tan, GIF, and LIF
- Exponential and power calculations
- Common and natural logarithms
- Sequential calculations
- Error handling for invalid operations

## Technologies Used

- C Programming Language
- Standard Input/Output Library (`stdio.h`)
- Mathematical Library (`math.h`)

## How to Run

1. Download or clone this repository.
2. Compile the source code using a C compiler:

   ```bash
   gcc calculator.c -o calculator -lm
   ```

3. Run the program:

   ```bash
   ./calculator
   ```

   On Windows, run:

   ```bash
   calculator.exe
   ```
